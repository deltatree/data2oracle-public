# UKE starten

Öffne `index.html` aus diesem Ordner im Browser.
Die Anleitung funktioniert auch ohne Internetzugriff.
Paketdownload und Modellvorbereitung benötigen eine Verbindung.

Führe alle Befehle aus diesem entpackten Ordner aus.
Beginne mit den Voraussetzungen und der Laufzeitprüfung.
Die Startskripte verwenden standardmäßig `ghcr.io/deltatree/data2oracle-runtime:main`.
Für einen festen Stand setze `UKE_IMAGE` auf `ghcr.io/deltatree/data2oracle-runtime:sha-41ca5a3742a0189da3891a2f50f4e4c9ea75f5b9`.

Die Originale liegen in `documents`, Modelle in `models`, Suchdaten in `knowledge` unter deinem gewählten `UKE_DATA_DIR`.
Das Archiv enthält keine Originaldokumente und keine Modelle.
Die Anleitung nennt Schutzgrenzen, Datenschutz und Lizenzbedingungen.
