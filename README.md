# UKE selbst betreiben

Die [öffentliche Anleitung](https://deltatree.github.io/data2oracle-public/) erklärt Installation, Betrieb und Quellenprüfung.

Du findest dort das Startpaket, Prüfsummen und Fremdquellen.
Das Startpaket enthält die Anleitung auch zur lokalen Nutzung.

UKE durchsucht deine eigenen Dokumente auf deinem Rechner.
Paketdownload und Modellvorbereitung benötigen Internetzugriff.
Lies vor dem Start die Voraussetzungen, Schutzgrenzen und Datenschutzangaben.
